1. Задача Codeforces

Доступны метаданные публичной задачи: название, рейтинг, теги. Текст условия не предоставляется официальным API. При блокировке CORS заполните поля вручную.

2. Генератор тестов

Переменные шаблона: {n}, {rand}, {i}, {array}. Случайные значения создаются в браузере.

3. Тесты и экспорт

ZIP содержит inputs/01.txt и answers/01.txt (если ответ введён). Для Polygon файлы можно затем добавить через его интерфейс. Прямая отправка в Polygon с GitHub Pages не реализована: для неё нужен отдельный сервер с защищённой авторизацией.
